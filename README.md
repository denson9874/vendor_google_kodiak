# Proprietary blobs for the Pixel 11 Pro XL (kodiak)

> **Still in use.** This repo is `vendor/google/kodiak` for the maintained device tree,
> [ExpressiveOS/device_google_kodiak](https://github.com/ExpressiveOS/device_google_kodiak)
> (branch `expressiveos`). The old tree at denson9874/device_google_kodiak is no longer updated.

Generated by `extract-files.py` from [device_google_kodiak](https://github.com/ExpressiveOS/device_google_kodiak)
(`proprietary-files.txt`) out of the stock factory image `CD1A.261005.003`.
These files are Google's, not ours. They're here so the device tree builds.

Clone to `vendor/google/kodiak`. The stock partition images (`vendor/google/kodiak-images`)
are generated separately by the device tree's `extract-images.sh` and aren't published.

`PixelCameraServices.apk` is over GitHub's 100 MB file limit, so it's stored with Git LFS.
Install [git-lfs](https://git-lfs.com) before cloning. If you cloned without it, or synced with
`repo`, run `git lfs pull` here. Otherwise that APK is only a small text pointer.
